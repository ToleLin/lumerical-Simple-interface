# LumEasy 使用說明

LumEasy 讓你不用學 Lumerical 的介面,直接輸入尺寸(或用滑鼠畫)就能建好 FDTD 模型、放好監視器、跑模擬、輸出資料與場圖。
它只透過 Lumerical 官方的 Python API(lumapi)溝通,**不碰授權、不碰授權伺服器**。

**滑鼠停在任何欄位或按鈕上,會顯示它是做什麼的、對應 Lumerical 的哪個設定。**

## 五分鐘上手

1. 工具列「範例」→ 選一個範例。右邊的預覽會畫出結構(俯視 + 兩個側視)。
2. 「1 專案」:選**存放資料夾**,按「連線測試」確認連得上 Lumerical。
3. 工具列右上「**執行模擬**」。下方狀態列會顯示進度。
4. 跑完到存放資料夾看結果:`<檔名>.fsp`(可以用 Lumerical 打開)、`<檔名>_results\`(資料與圖)。

## 座標與單位

- 原點 (0, 0, 0),**z 朝上**。工具列可以一鍵切換 nm / µm,數值會自動換算,模型不變。
- **2D** = x-z 截面(沿 y 無限長)。Lumerical 的 2D 其實是 x-y 平面,程式會自動轉換,你不用管。
- 數字欄可以直接打算式,例如 `2*150`、`(400-80)/2`。
- 工具列「簡易模式 / 進階模式」:簡易模式只顯示常用欄位;進階設定被改過時,簡易模式也會顯示出來。

## 各頁

| 頁面 | 做什麼 |
|---|---|
| 1 專案 | 檔名、存放資料夾、2D / 3D、單位、Lumerical 安裝位置與連線測試 |
| 2 材料 | 自訂材料:固定 n,k、固定 ε、匯入頻譜檔(n,k 或 ε 都可以,自動換算)、複製內建材料調擬合;附 n,k ⇄ ε 換算小工具 |
| 3 結構 | 「輸入尺寸」:清單 + 表單;「草圖畫圖」:在格子上畫矩形 / 圓 / 多邊形,再擠出或挖孔 |
| 4 光源 | 全域波長範圍;平面波、高斯光、波導模態、偶極子、TFSF |
| 5 模擬區 | FDTD 範圍(自動 = 物件 + 邊距)、邊界條件、網格精度、網格覆寫區;下方有網格與記憶體粗估 |
| 6 監視器 | 一鍵放上方 / 下方 / 左右前後 / 截面 / 點 / 封閉盒 / 折射率 / 時域 / 動畫;勾選要記錄的電場、磁場分量 |
| 7 執行與輸出 | 檢查設定、只建模型、建模並執行、從既有 .fsp 匯出;輸出格式;會送給 Lumerical 的腳本 |

## 建結構的方式

**疊層**:基板(「＋ 基板」,頂面在 z = 0)→ 薄膜(「＋ 薄膜」自動疊在最上面)→ 柱子(「疊在…的頂面上」選薄膜)。
改了下層的厚度,上面的東西會跟著移動。

**對齊點**(進階):物件的哪一點放在「偏移 x, y, z」——底面中心(預設)、幾何中心、底面角落,或原始座標(多邊形頂點 / CAD 檔案座標照原樣)。

**陣列**:陣列個數 > 1 就會在 Lumerical 裡複製(上萬個也很快),以偏移位置為中心排開。

**挖孔**:Lumerical 沒有布林減法。挖孔 = 放一個材料 `etch`(背景折射率)、網格優先順序 1 的物件蓋過去。

**特殊形狀**:「自訂多邊形柱」每行打一個頂點;或到「草圖畫圖」用滑鼠點。斜側壁用「梯形台」。

**CAD 匯入**:
- STL(3D 立體):Lumerical 原生匯入。檔案沒有單位 → 結構頁會列出每種單位解讀下的尺寸,點一下就換。
- GDSII:Lumerical 原生匯入,擠出成柱;cell 與圖層可以點選。
- DXF:程式把封閉的多段線 / 圓轉成多邊形。
- 一個 CAD 物件只能有一種材料,不同材料請分檔 / 分圖層各建一個物件。2D 時 GDS / DXF 的多邊形直接當 x-z 截面。

## 跑完會產生的檔案

| 檔案 | 內容 |
|---|---|
| `<檔名>.fsp` | Lumerical 模型(跑過的含結果),可以用 Lumerical 打開 |
| `<檔名>.lsf` | 建模腳本,貼進 Lumerical 的 Script 視窗可以重建同一個模型 |
| `<檔名>_project.json` | 這次的專案設定(可以用「檔案 → 開啟」讀回來) |
| `<檔名>_lumeasy_log.txt` / `_p0.log` | LumEasy 紀錄 / Lumerical 引擎紀錄 |
| `<檔名>_results\` | 依你選的格式:`.npz` `.mat` `.h5`(全部資料)、`*_spectrum.csv`(穿透率)、`*_E2_*.csv`(場分布)、`*.png`(場圖、頻譜、折射率)、`*_summary.json` |

同名檔案預設自動加 `_01`、`_02`,不會覆寫舊檔。

穿透率 T 對光源功率正規化;**負號代表功率往負方向流**(例如往下穿過下方監視器)。

## 自動檢查

- 開跑前:名稱重複、材料不存在、光源 / 監視器在模擬區外、2D 不支援的設定、記憶體與磁碟空間。
- 建模後:從 Lumerical 讀回每個物件的位置與尺寸,和設定比對。
- 跑完後:讀引擎 log 判斷有沒有發散、能量有沒有衰減完、穿透率有沒有超過 1。

常見問題見「疑難排解」。
